# スーパーカブ：モデリング資料

## 採用した方向性

1999〜2002年ごろの丸目スーパーカブ50・スタンダード（AA01系）を参考にした、アバグリーン × アイボリーのモデル。
写真を観察して造形したもので、メーカーのCADデータではありません。

- 全長の目安：1.800 m
- ホイールベース：1.175 m
- シート高の目安：0.735 m
- 前後17インチの細いタイヤとワイヤースポーク
- ボトムリンク式の前足、プレス鋼板フレーム、深い前後フェンダー
- 低床のステップスルーと、足元へ広がる立体的なレッグシールド
- 黒い一人用シート、クロームのリアキャリア、横型エンジンと右側マフラー

Blenderではメートル単位。書き出したGLBはY-up、前方が+Z、接地面がY=0です。
